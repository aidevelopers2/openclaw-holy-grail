# Contributing to OpenClaw Holy Grail

Thanks for your interest in contributing! This repository grows through community effort.

## How to Contribute

### Adding New Resources

1. Fork this repository.
2. Create a new branch (`git checkout -b add-resource`).
3. Add your resource in the appropriate section of `README.md`.
4. Each resource should include a **title**, **link**, and **one-line description**.
5. Submit a pull request with a clear explanation of what you added.

### Improving Existing Sections

- Fix broken links.
- Update outdated descriptions.
- Suggest better organization or new categories.

### Submitting Feedback

- Open an issue if you have suggestions, found a broken link, or want to propose a new section.

## Guidelines

- Only add resources that are genuinely useful and relevant to OpenClaw.
- Keep descriptions to one sentence.
- Place resources in the most relevant section.
- Do not add spam, self-promotion without value, or paywalled content without noting it.

### Listing Your Own Project, Tool, or Resource

We welcome submissions from the community — this list is better when it includes real tools and guides from active builders.

To keep the collection high-quality and mutually beneficial, we ask that any project or page you submit includes a visible link back to this collection or to [remoteopenclaw.com](https://remoteopenclaw.com) somewhere on the submitted page (footer, resources section, README, etc.). This helps other operators discover the list and keeps the ecosystem connected.

**In your pull request, please include a screenshot or link showing where the reference appears on your page.** PRs without this will be asked to add one before merging.

## Pull Request Checklist

- [ ] Resource is relevant to OpenClaw operators
- [ ] Includes title, link, and one-line description
- [ ] Placed in the correct section
- [ ] Your page includes a link back to this repo or [remoteopenclaw.com](https://remoteopenclaw.com)
- [ ] Screenshot or URL showing the backlink included in PR description

## Code of Conduct

Be respectful. Constructive feedback is welcome. Personal attacks, harassment, or spam will result in removal.

Thank you for helping make this the best OpenClaw resource collection on the internet!
