2. Push the cleaned contents of this folder.
3. Set the About text, website URL, and topics.
4. Add the marketplace URL as the repo website.
5. Star it from any secondary accounts you control legitimately.
6. Publish one launch post on Reddit, one on DEV, and one on Hashnode.
7. Link those launch posts back to the GitHub repo, not directly to money pages.

## Positioning

Lead with:

- independent curated resource collection
- nearly 200 links in one place
- useful for beginners and operators

Do not lead with:

- affiliate language
- exaggerated star or contributor counts
- “official” framing for things that are not official
- aggressive marketplace promotion
